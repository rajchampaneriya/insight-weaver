# Visual Assessment: Day 1-7 Images

A systematic review of each day's visual asset against the campaign's brand identity standards and LinkedIn optimization requirements.

---

## Brand Identity Compliance Checklist

| Standard | Specification |
|----------|--------------|
| Background | Deep Midnight Blue (#0A192F) or Charcoal (#121212) |
| Primary Accent | Electric Teal (#64FFDA) |
| Secondary Text | Muted Grey (#8892B0) |
| Alert/Warning | Soft Red (#FF6B6B) |
| Typography | Headlines: Inter/Roboto Bold. Body: Open Sans/Lato |
| Style | High contrast, clean lines, no stock photos, no clutter |

## LinkedIn Image Technical Requirements

| Requirement | Specification |
|-------------|--------------|
| Single Image | 1200 x 627 px (1.91:1 ratio) |
| Carousel Slide | 1080 x 1080 px or 1080 x 1350 px (portrait preferred) |
| Video Thumbnail | 1920 x 1080 px |
| File Format | PNG for images, PDF for carousels, MP4 for video |
| Max File Size | 10 MB per image, 100 MB for video |
| Text Legibility | Must be readable at 375px width (mobile) |
| Alt Text | Required for accessibility -- describe the visual content |

## Day-by-Day Assessment

### Day 1 Image: `Day-1 Image.png`

**Expected Content:** Dual-path flowchart (Innovation Death Spiral vs. Idea Factory Path)

**Assessment Criteria:**
- [ ] Background uses midnight blue (#0A192F) or charcoal (#121212)
- [ ] Teal (#64FFDA) accent on the positive "Idea Factory Path"
- [ ] Red (#FF6B6B) accent on the negative "Death Spiral" path
- [ ] No stock photos or decorative clipart
- [ ] Text is legible at mobile viewport (375px)
- [ ] Both paths are clearly distinguished at a glance
- [ ] No company logos or branding beyond personal brand
- [ ] Image dimensions: 1200 x 627 px or larger

**Key Risk:** If the flowchart has too many nodes or small text, mobile users will not be able to read it. LinkedIn's mobile app renders images at approximately 400px wide. Design for that constraint first.

## Overall Visual Recommendations

1. **Consistency is non-negotiable.** All 7 images must feel like they belong to the same series. Same color palette, same typography, same visual density. A viewer scrolling through your profile should immediately see a cohesive campaign.

2. **Mobile-first design.** Over 60% of LinkedIn consumption is on mobile. Every image must be legible at 375px width. Test this before publishing.

3. **Alt text for every image.** LinkedIn supports alt text. Use it. It improves accessibility and signals professionalism. Example: "Architecture diagram showing three layers: Experiment Execution, Evidence Collection, and Decision Support."

4. **File naming for organization.** Rename files to match the campaign structure: `day-1-flowchart.png`, `day-2-carousel.pdf`, etc. The current names (`Day-1 Image.png`) are functional but should be more descriptive for team collaboration.

5. **No watermarks or tool branding.** If images were created in Canva Free, ensure no watermarks are present. Use Figma (free tier) for professional-grade output.
